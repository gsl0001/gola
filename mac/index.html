Questions

How do I enter my licence key?

Open Gola's Settings, then General, and choose Enter licence key. Paste the key that starts with GOLA-. It is checked on your Mac; nothing is sent anywhere.

Why does it ask for Accessibility, Input Monitoring and Screen Recording?

Input Monitoring lets Gola notice the chord or mouse button that opens the wheel. Accessibility lets it focus windows and type dictated text. Screen Recording draws the live window previews and the frosted glass. The setup card walks through each one.

Does my Windows licence cover the Mac?

No. The Windows version is sold through the Microsoft Store, and the Mac version is sold here.

How does it update?

Gola checks for updates itself and installs them when you agree.

Where is my data kept?

Settings live in ~/Library/Application Support/Gola/. Nothing is uploaded.
