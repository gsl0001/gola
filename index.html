One gesture, held not clicked

hold · flick · release

  1. Hold the chord — CtrlAlt to start, any mix of Ctrl, Alt, Shift and Win after that, or a mouse thumb button.
  2. Flick to a slice. Dwell on an app and its windows fan onto the outer ring as live previews.
  3. Release on what you want. Release outside the wheel and nothing happens.

New in 1.0.5

Whatever's playing lives in the hub

Spotify, browsers and native players all land in the wheel's centre: album art, play/pause and track skip, a volume ring you drag or scroll, tap-to-scrub and one-tap mute. Space and the arrow keys work while the wheel is open.

This update makes the controls reliable on Edge and Chrome playback.

Your windows, fanned out live

App slices behave like taskbar buttons, one flick earlier. Not running — release launches it. One window — release focuses it. Several — they fan onto the outer ring as previews you slide straight onto, with New window always last. Green dots and counts show what's running at a glance.

Ten tools, no windows

Timer, calculator, colour picker, magnifier, clipboard history, screenshot, quick note, caffeine, focus dim and dictation. Each opens as a popover — no taskbar entry, no alt-tab stop. Esc closes it; the pin keeps it floating.

System, one flick away

Settings, Task Manager, Wi-Fi, Volume, Sleep and Lock, reached exactly like everything else — no hunting through the tray or the Start menu.

Tuned against a real wheel

Settings keeps a live wheel beside the window that redraws as you change it: five sizes, label length, fan depth, motion, themes. Everything writes straight to config.json and applies immediately.

What it touches

no account · no telemetry · no servers

A hold-and-flick launcher needs permissions that deserve a straight answer.

Keyboard hook
The only way Windows reports a key being held. Keystrokes are compared against your trigger and passed straight on — never recorded, never transmitted.
Screen capture
Draws the live window previews and the frosted backdrop. Images stay in memory on your machine.
Microphone
Only with dictation on, and only while you're dictating. Transcribed locally, then discarded.
Clipboard
Feeds the clipboard-history tool. Last twenty entries, memory only.
Network
Two connections exist: the one-off speech-model download, and api.telegram.org only if you set up your own bot.
Your files
%APPDATA%\Gola\ holds settings; %USERPROFILE%\Gola\ holds screenshots, notes and Shelf files.

Questions this app attracts

Is Gola spyware?

No. It installs a keyboard hook, captures screen content for the previews, and opens the microphone only if you turn dictation on — each is listed above with what it's for. There is no account, no telemetry and no server to send anything to.

Why did my antivirus flag it?

Keyboard hooks, screen capture and launching configured commands are together a heuristic match for what antivirus engines watch for. All three are required for a hold-and-flick launcher to work at all. The Store build is signed by Microsoft.

The wheel does nothing when I hold the chord

Almost always a trigger conflict: layouts that use AltGr — which Windows reports as Ctrl+Alt — collide with the default. Change it in Settings → Keymap to Ctrl+Shift.

Can I open it with the mouse, or a trackpad?

Settings → Keymap takes any combination of Back, Forward and Middle — hold and flick, or tap to leave the wheel open for a click. For a trackpad, pick Middle, then set Windows → Touchpad → Three-finger gestures → Taps to "Middle mouse button". Gola takes the button over, so it stops doing browser back/forward.

Extra buttons on gaming mice never reach Windows as mouse input — give one a keystroke assignment in your mouse software and set that as the chord instead.

Where does my data live?

%APPDATA%\Gola\ for settings, %USERPROFILE%\Gola\ for screenshots, notes, Shelf files and the speech model. Nothing leaves the machine.
