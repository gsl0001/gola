Gola

A radial launcher for Windows. Hold a chord, a wheel opens under your cursor, let go.

Setup

  1. Install from the Microsoft Store, then launch Gola once. It lives in the tray — there is no main window.
  2. Hold Ctrl+Alt. The wheel opens under your cursor.
  3. Slide toward a slice and release to run it. Release outside the wheel to dismiss.
  4. Right-click the tray icon → Settings to add your own apps and change the trigger.

If nothing happens when you hold the chord, see the wheel does nothing below.

The wheel

The inner ring is your apps plus the System, Tools and Shelf sections. The outer ring is whatever the slice you are pointing at contains — dwell for a moment to preview it without committing.

App slices behave like taskbar buttons: not running, release launches it; one window, release focuses it; several, the outer ring fans them out as live previews. A green dot and a count mean the app is open.

1–9 pick a slice directly. Esc closes. Dwell in the centre to go back up a level.

Tools

Timer, calculator, colour picker, clipboard history, magnifier, screenshot, quick note, caffeine and focus dim. They open as popovers rather than windows — Esc closes one, or pin it to keep it floating.

Shelf

A seven-day inbox of recent files with preview, search and archive. You can feed it from your phone by connecting your own Telegram bot: message @BotFather, run /newbot, then paste the token into Settings. Use a new bot — Telegram allows only one long-poller per bot, so a shared one would steal messages.

Dictation

With a text field focused, hold the chord and speak; Gola types what you said into that field. Speech recognition runs on your machine, not in the cloud. The first time you dictate it downloads a speech model (about 141 MB for the default) — that happens once, and everything after it works offline. Turn it off in Settings → Voice.

Common questions

Is Gola spyware?

No, and the question is fair — it does install a system-wide keyboard hook, capture the screen and open the microphone, so here is exactly why. The keyboard hook is the only way Windows lets an app notice a key being held and released; Gola checks whether the keys match your trigger and passes them straight on, and never records or transmits them. Screen capture draws the frosted backdrop and the live window previews, and stays on your machine. The microphone opens only while you are actively dictating. There is no telemetry, no analytics and no account. Full detail is in the privacy policy.

Why did my antivirus flag it?

Keyboard hooks, screen capture and running configured commands together are the exact pattern heuristic antivirus is built to notice, so false positives happen even though every one of those is needed for the product to work. The Store build is signed by Microsoft. If a scanner flags it, reporting it to that vendor as a false positive helps everyone.

The wheel does nothing when I hold the chord

Almost always a trigger conflict. On keyboard layouts that use AltGr — which Windows reports as Ctrl+Alt — the default chord collides with typing. Change it in Settings → Keymap to something like Ctrl+Shift.

My mouse thumb button doesn't trigger it

If your mouse has its own software (Logitech Options+, for example), leave that button set to the default Back/Forward there. A remapped macro or keystroke never reaches Gola as a button.

Where does Gola keep my data?

%APPDATA%\Gola\ for settings, and %USERPROFILE%\Gola\ for screenshots, notes, Shelf files and the speech model. Uninstalling removes the program; delete those folders to remove the data.
