Taskbar semantics, on a wheel

App slices do what a taskbar button does, in one flick. Not running, release launches it. One window, release focuses it immediately. Several, and they fan onto the outer ring as live previews you slide onto. Minimised windows can't be captured, so they show the app icon instead of a stale frame.

Ten popover tools

Timer with a sweeping ring, calculator with a click-to-copy result, colour picker that copies any pixel as hex, magnifier, clipboard history of the last twenty entries, screenshot, quick note, caffeine, focus dim and dictation.

System controls

Settings, Task Manager, Wi-Fi, Volume, Sleep and Lock, reached the same way as everything else.

Shelf — a seven-day inbox

Files that landed today on the left, a live preview on the right: images, text, markdown and code render inline, anything else shows its size. Enter opens, Delete archives, Ctrl+F searches. It keeps the last seven days, so nothing vanishes at midnight.

Phone → PC, through your own bot

Send a file, photo, link or note to a Telegram bot you created with @BotFather, and it lands in the Inbox within seconds and appears in the Shelf. The first sender to write is paired as owner; everyone else is ignored. Your token is encrypted with DPAPI and removed from the config file.

Side dock

A strip on the right edge holding what you parked — screenshots, saved notes, cards. Left-click to reopen, right-click to bin. It hides itself when empty.

Dictation, on your machine

Hold the chord over a text field, speak, and Gola types it where you were working. A 141 MB Whisper model downloads once, then it runs entirely offline. Off until you turn it on, because it opens the microphone.

Global shortcuts

Bind any tool to a combination that works without the wheel. Click the box, press the keys, done. A modifier is required, so a bare letter can never fire while you type. 

"hotkeys": {
  "screenshot": "Ctrl+Shift+S",
  "shelf": "Ctrl+Alt+B"
}

App switcher

An Apps › slice fans out your eight most recent windows in z-order. Flick to one, release, and you are in it — alt-tab without the row of thumbnails.

Pick your trigger

Settings → Keymap

Hold Ctrl Alt

Modifiers only — hold-flick-release needs a key that can be held. Click the chips in Settings to build any combination of Ctrl, Alt, Shift and Win.

Hold Ctrl + Alt

Ctrl+Alt is AltGr on some keyboard layouts. If typing gets strange, switch to Ctrl+Shift.

Mouse and trackpad

Back, Forward and Middle work as toggles — pick as many as you like, instead of or as well as the chord. Hold and flick as usual, or tap and the wheel stays open for a click.

Trackpad: choose Middle, then set Windows → Touchpad → Three-finger gestures → Taps to "Middle mouse button".

Gola takes its trigger buttons over, so a thumb button stops doing browser back. Leave that button on its stock action in your mouse software — a remapped macro never reaches Gola.

What it touches

No account · no telemetry · no servers

A hold-and-flick launcher needs permissions that deserve a straight answer. Here is each one, what it is for, and where the data stops.

Keyboard hook

The only way Windows reports a key being held. Keystrokes are compared against your trigger and passed straight on — never recorded, never transmitted.

Screen capture

Draws the live window previews and the frosted backdrop. Images stay in memory on your machine.

Microphone

Only with dictation on, and only while you are dictating. Audio is transcribed locally and discarded.

Clipboard

Feeds the clipboard-history tool. The last twenty entries live in memory and are never written to disk.

Network

Two connections exist. The one-off speech-model download, and api.telegram.org if you set up your own bot. Nothing else.

Your files

%APPDATA%\Gola\ holds settings. %USERPROFILE%\Gola\ holds screenshots, notes, Shelf files and the model.

Questions this app attracts

Type to filter

Is Gola spyware?

No. It installs a system-wide keyboard hook, captures screen content for the window previews, and opens the microphone if you turn dictation on. Each of those is listed above with what it is for.

Keystrokes are compared against your trigger and passed straight on. Screen capture stays local. There is no account, no telemetry and no server to send anything to.

When can I get it?

It is in Microsoft Store certification. There is no public build yet and no date worth promising, so: soon, and you will hear. Join the waitlist for exactly one email on the day.

Why did my antivirus flag it?

Keyboard hooks, screen capture and launching configured commands are together a heuristic match for what antivirus engines watch for. All three are required for a hold-and-flick launcher to work at all. The Store build is signed by Microsoft.

The wheel does nothing when I hold the chord

Almost always a trigger conflict. Layouts that use AltGr — which Windows reports as Ctrl+Alt — collide with the default. Change it in Settings → Keymap to Ctrl+Shift.

Can I open it with the mouse, or a trackpad?

Settings → Keymap takes any combination of Back, Forward and Middle. They work as toggles too: hold and flick, or tap to leave the wheel open for a click.

For a trackpad, pick Middle, then set Windows → Bluetooth & devices → Touchpad → Three-finger gestures → Taps to "Middle mouse button".

How do I add my own apps?

Settings → Apps, or edit config.json directly and reload from the tray. One entry per slice:

{ "type": "app", "label": "Claude",
  "path": "C:\\...\\Claude.exe",
  "match": "claude" }

match is the process name, needed when the executable that owns the window differs from the one you launch. Store apps embed a version in their path, so Gola self-heals those when they update.

Where does Gola keep my data?

%APPDATA%\Gola\ for settings, %USERPROFILE%\Gola\ for screenshots, notes, Shelf files and the speech model. Nothing leaves the machine.

Does it need Telegram?

No. The Shelf works on its own, watching your Inbox and Downloads folders. Telegram is an opt-in way to feed it from your phone, using a bot you create yourself — there is no Gola account or server in the path.
